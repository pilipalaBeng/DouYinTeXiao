| 体积 | 合计 **1.47 MB**（仅 PNG，未含音频）| 整包 ≤ 2 MB |

**判定**：这批图是 AI 生成原图的**直导**，从未经过 `tools/pixelize.py`。
对照 §1 的 17 张（512×512 / DB16 / 零半透明）可知：**管线本身是有效的**，问题出在**产物放置纪律**——`project/Assets` 只是 Effect House 的导入区，不该直接吃原图。

**待处置（独立一步，勿与本次清理混做）**：
1. 从 `assets/raw/` 重跑 `pixelize.py` → 产物覆盖 `project/Assets/` 同名文件；
2. 同步核对场景 `texture.key` 与各对象的 `width/height`（尺寸会变）；
3. 单张实测 `artifactFileSize`，回填 README §九 第 1、3 项。

## 4. 命名约定（宪法 §三）

```
正确：  boss_idle_pose_128.png     英文小写 + 下划线
错误：  像素飞行Boss待机.png        中文
错误：  BossIdlePose_128.png       驼峰 + 大写（历史遗留，待统一）
```

现行 `assets/px/` 存在**两套命名风格并存**（`BossIdlePose_128.png` vs `avatar_01_64.png`）。后续新增素材一律走小写下划线，历史文件在导出序列帧时顺带统一。

> ⚠️ 工程内中文名资产（`像素飞行Boss待机.png` 等）与场景 `texture.key` 一一绑定，**改名必须同步改 `scene.json` 的 key 与脚本常量**，只改文件名会断链。
