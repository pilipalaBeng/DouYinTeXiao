# 2D 游戏统一风格库

> 历史归档，禁止 `game2d-planner`、三份 Brief、设定图或棋盘图消费。当前唯一风格事实源是独立 Style RAG 链路产出的 LockedStyle，具体风格数据由 ByteRAG StylePack 管理。

以下内容仅保留用于对照旧四风格方案，不再参与运行时或 Prompt 选择。

## 风格选择

- 用户文字明确指定风格时，由文字决定全局风格合同：命中一种内置预设时完整采用对应预设合同；预设外风格或混合风格使用 `Style Ref: custom`，按统一合同格式扩写用户核心方向。有效用户风格图用于补充与该文字方向一致的视觉细节。
- 用户未明确指定风格时，再由有效风格图决定合同：主导风格稳定命中一种内置预设时完整采用对应预设合同；未命中内置预设时使用 `Style Ref: custom`，从图片中提炼统一合同；多张图片方向不一致时提取共同、可兼容的风格特征。
- 有效风格图具有可迁移的色调、材质、形状语言、描边、光照或游戏 UI 质感。完整游戏截图、游戏 UI、插画、概念图及具备上述特征的角色、道具或界面图片均可入选。规划阶段只负责候选判定，实际参考图筛选与传递由设定图生成阶段完成。
- 没有指定风格且没有有效风格参考图时，从 SVG 极简矢量、写实、像素、3D、工业机能五种预设中等概率选择一种；可先按玩法类型筛选适配风格，再在候选中等概率选择。SVG 极简矢量优先适配测试、测一测、抽签预言和轻量 UI 互动。
- 禁止混合多套预设。所有风格统一遵守移动游戏可读性、主体静止、低密度构图、实体不透明、安全视角、无前景边框、无霓虹发光和无真实摄影画面。
- 配色必须从命中的内置预设合同，或 `custom` 合同采用的用户文字与有效风格参考图中逐项推导；不允许使用任何通用审美经验、默认游戏 UI 配色、行业常见做法或自行补全合同中未定义的颜色名。
- 主要玩法对象、UI 背板、图标和文本表面必须承担不同视觉角色并保持足够对比；不得为任何资产引入全局风格合同未定义的低饱和度配色，也不得以柔和、耐看或统一等通用审美理由弱化警告色、道具色、文字色与主色之间的角色区分。

## 全局风格合同格式

UI Brief 必须只写一份以下合同，后续视觉描述不得建立第二套风格：

```markdown
### 全局风格合同
- Style Ref: <svg | 3d | pixel | industrial | realistic | custom | none>
- 风格来源：<用户文字 / 用户风格参考图 / 预设名称>
- 风格描述：<可直接用于生图的完整统一画风>
- 形状与材质：<轮廓、表面、描边、光照和阴影>
- 色彩角色：<主色调、配件色调、警告色、道具色、文字色；每项写明配色方案和应用范围，并补充项目色彩 DNA>
- UI 语言：<容器、按钮、图标和文字承载面的统一视觉语言>
- 禁止项：<与当前风格冲突且不得出现的视觉方向>
```

Visual Assets 只记录素材身份、形态、尺寸、构图、功能性色彩和生成约束；素材固有材质与身份特征写入 `描述/用途`，功能性色彩与抠图色写入 `配色/抠图色`。所有素材直接继承本合同。

## 通用配色纪律

Planner 将以下规则连同命中预设或 `custom` 的具体颜色一起展开到全局风格合同；设定图、棋盘和场景只执行该合同，不再各自维护第二套配色规则。

- **配色比例**：主色调 `65%`，配件色调 `22%`，警告色与道具色合计 `8%`，文字色与必要中性灰合计 `5%`，总和为 `100%`。
- **颜色数量**：同页面主色调不超过 `3` 种，配件色调不超过 `2` 种，警告色不超过 `1` 种，道具色不超过 `1` 种，文字色与必要中性灰不超过 `2` 种。
- **角色分工**：UI 底板、主要玩法对象、图标、文字和特效分别承担明确视觉角色；每个项目补充一句来自核心名词、动作、情绪、风险或幽默感的色彩 DNA。
- **角色推导**：按“主色调 → 配件色调 → 警告色 → 道具色 → 文字色”逐项使用合同规定的配色与应用范围，不得将一种角色的颜色挪给另一种角色，也不得自行从主色调推导合同外颜色。
- **可读性与克制**：避免大面积纯黑或纯白，避免文字与实际背景明度或色相过近；所有角色依靠色相、明度、轮廓和材质区分，不使用发光边框、发光图标、发光文字、发光特效、光晕、辉光或霓虹材质。
- **UI 容器禁止彩色灰**：禁止使用深蓝灰、橙灰、紫灰、绿灰等带明显色相的灰色；灰阶只允许 `R=G=B` 的纯中性灰。除全局风格合同明确采用的柔和低饱和、同色系浅色或奶感色系外，非灰色元素只使用合同定义的完全饱和纯色；不得把 SVG 合同颜色误判为彩色灰，也不得擅自提高其饱和度。
  - 正确：纯中性灰 `#999999`、纯橙色 `#FF8800`，以及 SVG 合同明确规定的浅紫色、浅米色和清透奶感色。
  - 错误：合同未定义的深蓝灰 `#4B5A6C`、橙灰 `#C4A8A0`，以及其它通过降低饱和度自行补出的带色灰。

## 公共 UI 风格词

圆角按钮、胶囊形按钮、描边按钮、不透明磨砂质感、极简图标、扁平图标、干净排版、文字清晰可读。

- Style Ref: `svg`
- 风格来源：内置 SVG 极简矢量预设；当前无固定风格参考图，只使用完整合同文本和筛选后的兼容用户风格图。
- 风格描述：治愈系扁平 UI、圆润萌感风格、轻量简约界面、柔和友好视觉、卡通化扁平设计、温润松弛质感，柔和低饱和配色、浅色系配色，无深/重色，马卡龙柔色调、清透奶感色系、低对比柔和配色、温润同色系微渐变、干净明亮基底、柔雾哑光质感，实心填充面性图标、圆润饱满扁平图标、无描边实心图标、可爱卡通实心符号、圆角几何实心图形、简约面性功能图标、萌系实心装饰元素、统一圆润造型的实心图标、实心扁平插画元素，大圆角矩形容器、柔和轻量卡片、极淡柔化投影、无粗描边卡片、通透轻盈卡片层级、圆润胶囊形按钮、轻量分段选项卡，扁平实心装饰插画、柔和弥散背景点缀、轻量几何装饰元素、圆润卡通 IP 形象、实心简约装饰符号、细弱分割线、宽松留白布局。
- 形状与材质：实心填充、圆润块面、统一圆角和干净边缘；容器保持连续实体表面，以极淡投影或明度差建立层级，不增加粗描边、纹理和复杂装饰。
- 色彩角色：

| 色彩角色 | 配色方案 | 应用范围 |
|----------|----------|----------|
| **主色调** | 清透奶感色系、低对比柔和配色；主要玩法主体使用唯一重色；设定图虚化氛围背景使用与元素拉开差异的浅紫色或浅灰白色，禁用重色 | 整体画面基调、主要玩法主体、设定图虚化氛围背景 |
| **配件色调** | 白色、浅紫色、浅米色等同色系浅色调 | 功能按钮面板、UI 控件底板 |
| **警告色** | 当前主题中唯一高对比色 | 必要危险提示和错误状态 |
| **道具色** | 对应色系浅色调 | 收集物、能量道具、增强道具 |
| **文字色** | 对应色系深色调 | 顶部数值、按钮和卡片文字 |

- UI 语言：大圆角矩形容器、柔和轻量卡片、圆润胶囊按钮、轻量分段选项卡、实心面性图标、细弱分割线和宽松留白；所有容器实体不透明。
- 禁止项：深重色系主导、粗描边、复杂纹理、玻璃态、空心容器、强投影、真实摄影、3D 体积建模、强透视、霓虹发光。

## 写实

- Style Ref: `realistic`
- 风格来源：内置写实预设。
- 风格描述：大众向轻拟真商业小游戏风，抖音互动特效与泛娱乐休闲游戏审美，核心玩法一眼可懂，角色与道具造型夸张醒目，写实材质贴图与低模半立体造型结合，局部加入抽象趣味元素、粒子反馈和轻度素材拼贴感，高饱和主色搭配强明暗对比，主体突出、反馈直接、信息层级清楚，界面按钮大而醒目，整体热闹、有梗、易传播，兼顾真实质感与低门槛娱乐感，避免过度精致、复杂叙事与小众艺术化表达。
- 形状与材质：游戏化轻拟真实体表面、写实材质贴图与低模半立体造型结合，使用克制高光、短阴影和清晰轮廓，不生成真实摄影画面。
- 色彩角色：

| 色彩角色 | 配色方案 | 应用范围 |
|----------|----------|----------|
| **主色调** | 哑光纯黑色 | 整体画面基底 |
| **配件色调** | 中灰、浅银灰色 | 功能按钮面板、UI 控件底板 |
| **警告色** | 亮橙色 | 危险提示、状态警示、特效 |
| **道具色** | 正红、亮黄及主题道具色 | 收集物、能量道具、增强道具 |
| **文字色** | 纯白色 | 顶部分数数字、所有按钮标识文字 |

- UI 语言：完整采用公共 UI 风格词，保持按钮大而醒目、信息层级清楚、实体圆角卡片和轻拟物按钮；中灰、浅银灰用于容器外层，纯白运行时文字使用连续平整的纯黑 `#000000` 实体承载面，该区域不受材质高光或渐变影响。
- 禁止项：照片级真实、真实人体皮肤、摄影光照、电影镜头、景深虚化、透明玻璃、复杂纹理、强透视、霓虹发光。

## 自定义

- Style Ref: `custom`
- 仅在用户文字和有效风格参考图均未稳定命中单一内置预设时使用。完整保留其中共同、可迁移的色调、材质、形状语言、描边、光照和游戏 UI 质感，不强行归入最接近的预设。
- 将用户风格转换为适合 2D/AR 移动游戏的安全表达：统一视角、实体不透明、低密度、清晰轮廓和高可读 UI；只移除真实摄影、强透视、前景边框、包围式装饰、玻璃态和霓虹发光等禁止项。
- 多张有效风格图存在冲突时，以用户文字明确指定的方向为准；文字未指定时提取共同风格，不拼接互斥特征。
