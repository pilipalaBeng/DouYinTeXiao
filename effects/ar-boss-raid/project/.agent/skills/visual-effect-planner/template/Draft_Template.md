# 视觉交互特效草案模板
将用户的初始 Prompt 扩写为可确认的视觉特效草案时，使用 Markdown 列表分段语法，但根据创作意图决定标题、数量和内容，不套用固定栏目。。

```markdown
- **动态标题**

  内容
```
## 组织原则

通常保留以下通用内容：
- `一句话概念`：一句话说明最终可见结果与核心吸引力。
- `核心视觉表现`：说明主体的颜色、形态、材质、合成或其他关键变化，以及效果如何出现、跟随、增强、叠加、衰减、消散、恢复或稳定保持。

以下模块仅在效果实际需要时补充，例如：

- 语义区域效果：目标区域、隔离边界、羽化、遮挡和不受影响区域。
- 手势、表情或身体互动：输入动作、连续/离散映射和无输入状态。
- 全屏滤镜或后处理：全局画面变化、主体保护、空间层次和强度演进。

## 扩写原则

1. **最终画面优先**：先明确用户真正想看到的视觉结果，再组织作用对象、输入映射和动态过程。明确的画面目标优先于模糊的技术称呼（如“粒子”“材质”“后处理”只是手段）。
2. **作用范围明确**：区分全屏、主体、局部语义区域、特定对象和周边空间。必须从描述中识别效果作用于何处，并说明哪些区域不受影响，确保语义区域隔离。
3. **输入映射闭合**：识别手势、表情、动作、触摸、录制或持续时间触发；明确输入如何映射到位置、范围、强度、颜色、形变、显隐等属性。离散动作需说明阶段变化，连续输入需明确跟随趋势和消失后的行为。
4. **视觉层次清晰**：区分核心效果、辅助反馈和环境氛围。主效果、辅助反馈应形成清晰层次，辅助元素不得遮蔽主体或破坏语义逻辑。
5. **动态过程完整**：草案必须形成“输入或触发 → 核心视觉变化 → 动态反馈 → 消散、恢复或稳定保持”的闭合链路，补全效果成立所需的最小生命周期。
6. **现实物理可信度**：扩写现实世界的动态现象时，优先复刻其真实物理状态和连续变化，必须使用材质实现，不得用静态图片素材或贴图平移近似。
7. **最小合理补全**：仅补齐使视觉目标可理解、互动映射可执行和动态过程连续所必需的层次与反馈。未提供的具体数值参数保持为定性描述，交由 Brief 阶段确定。
8. **参考内容忠实**：提取参考图/视频的构图、材质、色彩、运动等特征；不得添加参考中不存在且会改变主体效果的装饰。
9. **歧义处理与能力边界**：忠实表达意图，不因能力暂缺就主动降级。通过上下文、因果关系和视觉语义排除非关键歧义；只有多个解释会导致不同的作用对象、输入源或核心互动关系时，才由 Planner 发起澄清。

## 意图还原细则

生成草稿前，必须从用户 Prompt 中识别并关联以下事实，确保逻辑一致：

- **语义还原**：不得因为多个视觉名词并列就拆成独立效果。每个元素的职责必须由它与作用对象、输入映射和最终画面的关系共同确定。
- **推断补全**：用户未完整说明链路时，补全使效果成立的最小结构。区分离散与连续驱动，确保输入、作用范围和视觉响应一一对应。
- **歧义过滤**：能够通过全文或参考内容排除的解释直接排除，不因单个模糊词语触发澄清；技术路线不同但视觉结果等价时，不在 Draft 阶段询问。

## 意图理解对比示例

用户输入：张开手掌时，让身体周围出现蓝色能量场，手移动时带出光轨，握拳后能量聚拢并消失，人物本身不要变色。

错误扩写（不应出现）：

```markdown
**一句话效果**

  在画面上添加蓝色互动特效。

**核心视觉表现**

  全屏持续覆盖高亮蓝色粒子，任意手势都会增强粒子，握拳后显示结果。

```

正确扩写：

```markdown
**一句话效果**

  用手唤起环绕身体的蓝色能量场，并以连续光轨强化手部运动。

**核心视觉表现**

  能量只分布在身体轮廓外侧及双手运动路径周围，人物肤色、服装颜色和远处背景保持原样。身体外缘形成半透明蓝色能量层，内部有沿轮廓流动的细密光纹；手部移动时拉出具有亮核和柔和衰减边缘的光轨。张开手掌时能量场渐显，手部位置与移动速度连续控制光轨位置、长度和亮度，握拳时先向身体中心快速聚拢再逐渐熄灭。

```

### 扩写解析

- “蓝色能量场”“光轨”是同一交互效果的主体层和运动反馈层，不应拆成多个无关模式。
- 张掌、移动、握拳分别对应出现、连续驱动和收束消失，构成完整生命周期。
- “人物本身不要变色”是明确的隔离约束，不能用全屏染色近似。

## 输出格式示例

### 语义区域效果

```markdown
**一句话效果**

  只让天空区域出现缓慢流动的极光，建筑、人物和地面保持原始画面。

**核心视觉表现**

 极光严格限制在天空语义区域内，并被建筑与人物前景正确遮挡，天空边界随画面内容稳定更新。多层半透明光带形成纵向褶皱和柔和辉光，颜色在青绿与淡紫之间连续过渡；录制期间持续根据天空区域驱动并缓慢漂移，亮度有克制的呼吸变化，区域暂时丢失时平滑减弱，重新识别后自然恢复。

```

### 手势交互效果

```markdown
**一句话效果**

  手掌部移动时在空气中绘制发光水波，张开手掌扩大波纹，握拳让波纹向掌心回收。

**核心视觉表现**

 视觉反馈围绕手部位置和已形成的运动轨迹展开，不改变人物与背景本身。波纹具有清晰亮核和透明外缘，手部位置控制波纹中心，移动速度影响拖尾长度，张掌连续放大波纹范围，握拳触发聚拢与消散；输入变化经过平滑后驱动画面，手势切换时连续过渡，短暂丢失保持上一状态并柔和衰减。快速移动时轨迹连续，不因检测轻微抖动产生闪烁或断裂，并与复杂背景保持足够区分度。

```

## 输出规则

1. 使用上方规定的分段格式，标题和模块数量必须由当前创作意图决定。
2. 通常保留一句话概念、核心玩法或核心互动、视听反馈；其他模块按需出现，不为填满模板增加无关机制。
3. 优先展开用户 Prompt 和参考内容中明确提出的视觉目标，再对缺失部分做不改变方向的必要补全。
4. 草案必须具体、精练且易读，善用短段落或简短分点，不写冗长规则和实现细节。
5. 只输出填写完成的 markdown 内容块，不输出示例标题或额外说明。
