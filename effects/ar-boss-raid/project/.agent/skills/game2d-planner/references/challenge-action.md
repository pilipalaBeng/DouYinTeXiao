# 挑战操作创作规划

> 读取时机：Draft 确认后，主要乐趣是反应、操控、时机、移动、瞄准或空间判断时读取
> 职责边界：只补充挑战操作的玩法 Brief，不定义素材、布局、API 或固定代码结构

## 适用判断

玩家主要时间用于反复执行一个操作并处理目标、风险、时机或空间变化时使用，例如跳跃落点、躲避穿越、接物、跑酷、射击、防守、蓄力和精准点击。

## 核心循环

- 建立 `观察目标/风险 → 输入 → 运动或判定 → 即时反馈 → 新目标/结束` 的短循环。
- 明确核心输入直接控制的量及其与成功判定的关系；移动、瞄准、蓄力或选择玩法让输入改变位置、方向、力度、轨迹或目标。时机点击等仅触发动作的玩法让机会按可见规律进入固定判定区，并提供稳定、可预判且足够宽松的操作窗口。
- 同时存在安全与危险候选时，让玩家通过可观察的时机窗口、位置或方向选择目标或落点，使不同合法输入形成不同路径和结果，并始终保留可达的安全选择。
- 第一次有效输入使用宽松、可达的学习窗口，让玩家从画面理解自己的输入如何改变结果，以及下一次如何做得更好。
- 正常成功、精准成功、失误和无效输入具有不同逻辑结果与反馈，一次操作只结算一次。
- 每次成功后出现可见、可达、可判断的下一目标，或进入当前设计明确的完成状态。

## 挑战变化

- 从目标位置或组合、速度、距离、间距、尺寸、判定窗口、风险或奖励中选择少量维度渐进变化，保持已建立的控制含义。
- 变化形成可预判的学习、稳定、提升和短高潮节奏。
- 奖励精准落点、连续成功、擦边通过或快速反应等高质量操作，但额外奖励不阻断基础推进。
- 生命、分数、敌人、Boss 或道具仅在实际玩法需要时出现，并服务于主要操作。

## 空间持续性

- 生成位置、视觉目标、运动终点、命中判定和边界衔接共享同一坐标事实。
- 可点击目标旋转、倾斜或发生其它非轴对齐变换时，点击判定区按最终可见方向、尺寸和位置同步变换；细长目标使用覆盖完整可见主体的触控容差，并在 gamelogic Brief 记录判定形状、容差和边界输入。
- 推演若干次连续成功后的角色、目标和运动范围；接近边界前使用方向折返、等效滚动、对象回收补充或安全结束。
- 每轮运动的完整轨迹和下一目标保持可见；方向变化后仍保留合理距离、判断窗口和清晰推进趋势。
- 动态生成内容先保证可达和可反应，再增加随机性。

## 失败与恢复

- 碰撞、越界、过早或过晚输入、目标丢失和多个结果同帧命中具有唯一判定与仲裁顺序。
- 以躲避危险对象为核心目标时，只有用户或参考事实明确提供生命、护盾、扣分、复活或其它可恢复机制，碰撞后才继续；未定义可恢复机制时，碰撞即失败并进入稳定结算，不得自行补成受击闪烁、无敌后继续。
- 失败反馈说明原因，并进入 Brief 定义的稳定失败、继续、降级或安全结束；明确碰撞结果、结束条件和结算字段。
- RecordEnd 停止输入、运动、生成器、timer 和音频，取消未完成过渡并保留最近已提交的稳定阶段；下一次 RecordStart 再清理动态对象并恢复角色、目标、方向或滚动基准、数值与 Preview。

## Brief 必需事实

- 主要操作、玩家可控量、输入范围、目标、成功/精准/失败判定和反馈；仅触发动作时写明机会出现规律与判定窗口。
- 玩法包含方向敏感对象的运动、命中或附着时，记录素材 `0°` 朝向、参与判定的对象端点、目标接触点和命中后需重合的端点关系；端点与接触点使用最终显示矩形内的归一化位置表达。
- 仅时机控制且目标或判定区移动时，写明输入至判定的持续时间、最不利可生成状态下的相对位移、最小有效输入窗口，以及没有可达安全选择时的重采样或约束规则。
- 每轮如何产生下一目标，以及挑战在哪些维度、何时、以何种幅度变化。
- 多轮成功路径、边界衔接、按通用玩法质量完成的数值可达性推导与正安全裕量、失败仲裁和 reset。
