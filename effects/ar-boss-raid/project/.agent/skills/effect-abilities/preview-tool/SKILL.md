# Preview 工具

## 触发边界

仅在以下任一条件成立时使用此 Skill：

- 用户明确要求操作预览、验证交互行为、截图、录制或读取 Preview 运行时证据；
- `preview-verification` 已明确进入视觉质量审查流程并委派 Preview 操作；
- 经过多轮沟通仍无法准确理解或定位用户描述的画面表现或 Bug 现象，且仅凭静态信息无法继续排查，需要使用截图和日志补充运行证据。

不得因为游戏或特效制作完成、编译成功、场景结构检查通过、需要“验证后结束”或任务收尾而主动使用本 Skill。普通制作任务以编译和场景结构检查作为默认验证，不自动截图、重置预览、模拟录制或执行交互。

本 Skill 提供截图、触摸与拖动、预览生命周期控制、视频录制、运行时属性传输和日志读取能力。

触发本 Skill 后，在编写或执行任何 Preview 命令前，必须按需阅读 [Preview工具.md](./Preview工具.md)；执行预览录制或行为验证时，必须遵守其中的[执行原则](./Preview工具.md#执行原则)和[行为验证停止门禁](./Preview工具.md#行为验证停止门禁)。该文档是命令参数、调用示例、执行模式和录制语义的唯一事实源。

## 与视觉验证的边界

本 Skill 只定义 Preview 操作接口和通用行为验证方法，不负责判断画面是否精致、统一或符合设计目标。

当任务要求视觉质量审查、分阶段截图评分、视觉缺陷修复与复验时，使用 [preview-verification](../../preview-verification/SKILL.md)。该 Skill 可以调用这里定义的 Preview 接口，但视觉审查标准、独立重置门禁和截图缺陷债务仍以 `preview-verification` 为准。
