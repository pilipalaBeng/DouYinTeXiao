# 面部检测

## 使用范围

当玩法需要根据人脸位置、关键点、旋转角度或特定面部动作（FaceAction）产生实时反馈时使用。

启用本能力时，调用 `setupGameScript`，并按 Detail 标题原样传入能力名：

```json
{"abilities":["面部检测"]}
```

## 规划与设计约束

### 1. 人脸避让（重要）
游戏叠加在实时摄像头画面上，重要 UI 和玩法内容必须避让人脸区域以保证用户体验：
- **额头/头顶区域**：当上半屏能提供受保护的玩法区域和足够独立的信息栏通道时，优先将复杂或频繁点击的元素缩放并锚定在此区域。
- **胸部悬浮区**：当下方安全区域能形成更干净布局时使用。应将玩法对象缩放至适合可用安全空间的大小。
- **UI 布局优化**：若 UI 遮挡过多画面，应优先缩小尺寸、拆分为更小的实体不透明容器，或改为阶段性显示，不得通过使用半透明或镂空底板来规避避让原则。

### 2. 交互方式
支持通过面部追踪驱动游戏对象。常见控制包括人脸位置跟随、旋转角度驱动物体倾斜、或通过眨眼、张嘴等 FaceAction 触发事件。

## 可用信息

通过 `this.vision.getFaces()` 获取当前帧的检测结果，每个结果包含：
- `box`: 人脸在屏幕上的归一化包围框。
- `landmarks`: 106 个原始归一化关键点。建议使用 `getPart(part)` 接口获取语义部位坐标。
- `rotation`: 头部旋转角度（Pitch/Yaw/Roll），单位为弧度。
- `hasAction(action)`: 判断是否触发特定动作，如 `EyeBlink`、`MouthAh`、`BrowJump` 等。

## 脚本集成规则

仅对 `*.Result`、`Face.Attr` 等 Vision 结果对象、数组及回调参数显式标注类型；`number`、`boolean`、`Point2D` 等普通值可由 TypeScript 推断。调用 `hasAction` 的对象必须显式声明为 `Face.Result`。

```ts
import { Face, install, Vision } from './Vision';

// 场景字段
public vision!: Vision;

// ... 场景初始化中
this.vision = install(this);

// ... 每一帧更新中
const faces: Face.Result[] = this.vision.getFaces();
if (faces.length > 0) {
  const face: Face.Result = faces[0];
  // 获取嘴巴中心点用于放置挂件
  const mouthPos = face.getAnchor('mouth', 'center');
  // 判断张嘴动作
  if (face.hasAction('MouthAh')) {
    // 触发逻辑
  }
}
```
