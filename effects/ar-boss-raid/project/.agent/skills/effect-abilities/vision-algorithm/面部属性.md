# 面部属性

## 使用范围

当玩法需要识别用户的表情强度、年龄、性别或颜值（吸引度）等统计学/语义化属性时使用。

启用本能力时，调用 `setupGameScript`，并按 Detail 标题原样传入能力名：

```json
{"abilities":["面部属性"]}
```

## 可用信息

通过 `face.getAttr()` 获取面部属性数据，包含以下维度：

### 1. 表情 (Expression)
- **类型 (type)**: 当前置信度最高的表情，包括：`Angry` (生气), `Disgust` (厌恶), `Fear` (恐惧), `Happy` (快乐), `Sad` (忧伤), `Surprise` (惊讶), `Neutral` (平静), `Unknown` (未知)。
- **概率分布 (probs)**: 各表情对应的原始概率数组。
- **快乐分 (happyScore)**: 范围 0..100，反映用户的微笑或大笑强度。
  - **参考阈值**：~30 to 50 为微笑 (Smile)；> 60 为大笑 (Laugh)。

### 2. 统计学属性 (Demographics)
- **预估年龄 (age)**: 检测到的人脸年龄。用于展示年龄文案时，建议使用 `Math.round(age)` 取整。
- **性别 (gender)**: `Male`, `Female` 或 `Unknown`。
- **颜值分 (attractive)**: 吸引度评分。

**注意**：统计学属性（年龄、性别、颜值）由深度学习模型推断，旨在用于趣味互动，不宣称为绝对真实的数据，且 API 不提供针对这些属性的单一置信度得分。

## 脚本集成规则

仅对 `*.Result`、`Face.Attr` 等 Vision 结果对象、数组及回调参数显式标注类型；`number`、`boolean`、`Point2D` 等普通值可由 TypeScript 推断。调用 `getAttr` 的对象必须显式声明为 `Face.Result`。

```ts
import { Face, install, Vision } from './Vision';

// 场景字段
public vision!: Vision;

// ... 场景初始化中
this.vision = install(this);

// ... 每一帧更新中
const faces: Face.Result[] = this.vision.getFaces();
const face: Face.Result | undefined = faces[0];
const attr: Face.Attr | undefined = face?.getAttr();
if (attr) {
  const happyScore = attr.expression.happyScore;
  const age = Math.round(attr.demographics.age);
  // 根据快乐分控制特效反馈
  if (happyScore > 60) {
    // 触发大笑奖励逻辑
  }
}
```

## 结果映射与防抖
面部属性计算开销较大且易受环境光线影响，结果可能随帧波动。
- **映射规则**：建议根据业务需求将连续得分（如 `happyScore`）映射到离散的玩法状态。
- **默认策略**：若检测失败或属性缺失，应提供合理的默认逻辑（如维持上一帧状态或使用默认文案）。
- **防抖推荐**：对于表情触发逻辑，建议配合 `StateTracker` 进行时间防抖（如持续 300ms 达到阈值），避免反馈过于跳跃。
