## 创意描述

**AR 像素 Boss 战 · 转手机打怪**

打开特效，手机镜头就是你的战场：一只像素风飞行怪（张开双翼、红色圆眼、头顶小角）会"咚"地**锚定在你身边的真实空间**里——你转动手机，它就跟着在画面里滑动，像真的悬在你面前。屏幕正中始终悬着一枚像素准星，屏幕下缘伸出一把 AK 造型的像素枪。

**转动手机**把飞行怪转进准星，**按住屏幕**持续开火，把它打服认输：血条三阶段递进——先热身（常态摆动）→ 再暴怒（喷像素弹幕、召唤小怪）→ 最后举盾 + 装死，打空血条后 Boss 举手投降、头顶"出战牌"落地、炸出彩带与像素星，弹出「胜利！」结算卡。

进局前还能从 **6 款像素头像里选一个**，挂在 Boss 头顶当"出战牌"；打完把带头像的结算卡甩给朋友，梗就有了。

风格：**像素风**（16 色 DB16 色板、点采样、512×512 贴图），全程无血、无惨叫，Boss 是"认输"不是"死亡"。

## 互动方式

- **转动手机（6DoF）**：改变镜头朝向，把锚定在真实空间的 Boss 转进**屏幕正中的固定准星**（准星不可拖拽）；
- **按住屏幕开火**：按下开始连射（4 发/秒），抬起停火；
- **人脸动作（张嘴 / 眨眼）**：触发一次**重击**，打断 Boss 当前动作；
- 命中瞬间给足反馈：**闪白 + 震屏 + 伤害数字 + 像素星 + 枪口闪光 + 音效**，同帧触发；
- 准星进入命中容差圈时高亮提示，Boss 微放大 + "嘀"声。

> 触发方式全程**只有 2 种**（① 按住开火 ② 人脸事件=重击）；「转手机」属操控输入，不计入触发额度。

## 可选补充

**计分 / 评级**
- 结算卡显示：耗时、命中率、最高连击，并给 **S / A / B / C** 评级；
- S = 时限内剩余时间 ≥50% 且命中率 ≥70%；A = 命中率 ≥60%；B = 通关；C = 未通关；
- 复玩驱动：刷 S 评级、最短耗时挑战、换出战对象再战。

**Boss 三阶段机制**
| 阶段 | 血线 | 机制 |
|---|---|---|
| 常态试探 | 100%→66% | 缓慢摆动，无攻击（教学/暖场） |
| 暴怒 | 66%→33% | 眼睛变红、速度加快，喷像素弹幕 + 召唤 2 只小怪挡身前 |
| 护盾 + 假死 | 33%→0% | 举盾（HP 冻结）→ 打闪烁**核心点约 3 次破盾** → 2s 全额伤害窗（最多回盾 2 轮）；HP≈15% 时**装死 0.8s**，停火会被回血 5% |

**关键数值（仅供参考）**
- Boss 血量 2400 / 普通命中 80 / 核心命中 120；
- 射速 4 发/秒（闸门 250ms）/ 弹匣 12 发 / 换弹 1.0s；
- 单局时限 40s，熟练 12–16s 通关，中位约 30s；
- 准星命中容差 0.17（视口归一化）。

**互动规则 / 边界**
- 触发方式恰好 2 种，不叠加第三种；
- 全程离线可跑：无服务器下发、无外链、无账号级好友拉取；
- 头像双轨：默认＝内置预设 6 选 1（零真人照片、零上传）；增强＝摄像头取像（不存储 / 不上传 / 不导出，仅存活本局纹理）；
- 风格统一：DB16 16 色、Nearest 采样、图层 ≤6、粒子 ≤50、包体 ≤2MB。
