# ar-boss-raid · 玩法与特效总结

> 一句话：**把手机镜头当枪**——Boss 是一只**锚定在真实空间**里的像素飞行怪，**转动手机**把它转进**屏幕正中的准星**、**按住屏幕开火**，把它打服认输的抖音 AR 像素射击特效。
>
> 本文是**玩法 + 特效表现**的汇总视图，方便快速通读；数值与口径的**权威来源仍是** `game-design-doc.md` / `vfx-spec.md` 等规格文件，冲突时以规格文件为准。
>
> 状态：**玩法链路已跑通（PC 预览）**；**真机 SLAM 手感待验**；完整工程未开工。

---

## 一、30 秒看懂玩法

| 步 | 玩家做什么 | 系统给什么反馈 |
|---|---|---|
| 1 进局 | 镜头对准房间；**预设像素头像 6 选 1**（3s 无操作自动用默认款，不阻断） | Boss"咚"地锚定在真实空间，头顶立起"出战牌" |
| 2 瞄准 | **转动手机**（6DoF），把 Boss 转进**屏幕正中的固定准星** | 进容差圈（0.17）→ 准星高亮 + Boss 微放大 +"嘀" |
| 3 开火 | **按住屏幕持续开火**（4 发/秒） | 枪口闪光 + 后坐力 + 命中闪白/震屏/伤害数字/像素星 |
| 4 终结 | 把血条打空 | Boss 举手认输 + 出战牌落地 + 彩带星星 + 结算卡 |

**单局 20–40 秒，中位 30 秒；熟练 12–16 秒通关。40 秒未击杀判失败，一键重开。**

## 二、操控与触发方式

| 项 | 内容 |
|---|---|
| **瞄准** | 准星**固定屏幕正中**（不可拖拽）；靠**转手机**移动 Boss 的投影位置 |
| **开火** | 手指**按下开始 / 抬起停止**，闸门 250ms = 严格 4 发/秒 |
| **重击** | **人脸事件（张嘴/眨眼）= 重击/打断** Boss 当前动作 |
| **触发总数** | **恰好 2 种**（① 按住开火 ② 人脸事件）；「转手机」属操控输入，**不计入触发额度** |
| **命中判定** | Boss 世界坐标 → `worldToViewportPoint()` 归一化视口坐标；`|vp.x−0.5| ≤ 0.17 且 |vp.y−0.5| ≤ 0.17` 即命中（`vp.z ≤ 0` 判未命中） |

## 三、Boss「飞行怪」三阶段

| 阶段 | 血线 | 机制 | 玩家应对 |
|---|---|---|---|
| **1 常态试探** | 100%→66% | 缓慢摆动，无主动攻击（教学/暖场） | 熟悉瞄准与开火 |
| **2 暴怒** | 66%→33% | 眼睛变红、体型微胀、摆速加快；周期性**喷像素弹幕**（只扣连击/短暂致盲，非硬判定）+ 召唤 2 只小怪挡身前 | 保持连射，抽空清怪或硬抗 |
| **3 护盾 + 假死** | 33%→0% | ① **开盾**：护盾期 **HP 冻结**；打身体 −6%/发（慢），打闪烁**核心点** −34%/发 → **约 3 次核心破盾** → 2s 全额伤害窗 → 回盾上限 **2 轮**。<br>② **假死**：HP≈15% 时瘫倒装死 0.8s，停火会被回血 5% | 抓核心破盾；假死时**别停火** |

> 阶段切换用「**震屏 + Boss 变色 + 像素台词**」三件套，同帧触发，1 秒内可感知。

## 四、特效表现层（打击感配方）

### 4.1 受击四件套（同帧触发）

| # | 元素 | 说明 |
|---|---|---|
| 1 | **微顿帧 hitstop** | 命中瞬间冻结 Boss 动画 + 屏蔽输入，L4 特效照常跑 |
| 2 | **闪白 + 抖动** | 本体 1–2 帧纯白覆盖 + 位移抖动（走 Boss 世界空间加法位移） |
| 3 | **伤害数字** | 从命中点弹起上飘；暴击数字更大更黄（`#dad45e`） |
| 4 | **像素星 + 音效** | 每次溅 3–5 个像素星，配"啪/咚"声 |

### 4.2 hitstop 与震屏参数

| 场景 | hitstop | 震屏位移 |
|---|---|---|
| 普通命中 | 50 ms | 0.5 px |
| 暴击 / 核心 | 67 ms | 1.5 px |
| 破盾 | 83 ms | 3 px |
| 暴怒 | — | 4 px |
| 认输 / 失败 | 0 ms | 3 px / 2 px |

> 震屏作用于 `ContentRoot`（不占图层），**单帧位移硬上限 4 px、只平移不旋转**。

### 4.3 击杀演出（去暴力化）

HP 归零 → ① Boss 举手投降、眼睛弯成 `^ ^` ② 出战牌"啪"落地 ③ **彩带 20 + 星星 8 = 28 粒子**同帧 burst ④ 蹦出「胜利！」与结算卡。
**全程无血、无惨叫、无身体破坏**，语义 = "认输 / 被放倒"。

### 4.4 粒子预算

全场 **≤ 50**（现实峰值 36；理论全叠加 50 = 红线本身；运行时预算管理器软顶 46，超限自动降级）。

### 4.5 六层渲染结构

| 层 | 内容 | 体系 |
|---|---|---|
| L1 氛围装饰 | 留空（降级首要牺牲位） | — |
| L2 Boss 主体 | 3D 世界锚定 `ImageEntity` + 出战牌 + 闪白遮罩 + 护盾 + 核心点 | **3D 世界坐标** |
| L3 武器 | AK 像素枪 + 屏幕正中准星 + 枪口闪光 | 2D 屏幕 |
| L4 命中特效 | 像素星 / 破盾碎片 / 暴怒脉冲 / 彩带星爆 / 伤害数字 | 瞬时 |
| L5 HUD | 血条（红条 + 护盾蓝条 + 阶段刻度）/ 提示文案 | 常显 |
| L6 状态页 | READY / WIN / LOSE 结算卡 | 状态切换 |

> 音频对象（26 个 = 2 BGM + 24 SFX）**不占图层**，统一挂常驻 `AudioRoot`。

## 六、合规底线（不可放宽）

| 项 | 做法 |
|---|---|
| **去暴力化** | 全程无血/无伤口/无惨叫；统一用「放倒 / 认输 / 挑战成功」；**禁用红色 `#d04648` 做命中粒子**（会被读成血），红色只留给血条与暴怒眼睛 |
| **头像双轨** | **轨 A（默认）**＝内置预设 6 选 1 像素头像，零真人照片、零上传；**轨 B（待验增强）**＝摄像头取像，不存储/不上传/不导出，仅存活本局纹理；**两条轨道都不读相册、不导入外部照片** |
| **头像定性** | 头像被做成 **16×16/24×24 静帧小相框**，挂在头顶当"出战牌"，**不是把真人脸贴成 Boss**；不做换脸、不做表情驱动 |
| **零人声** | 全包不含任何人声采样 / TTS |
| **不做** | 复杂 3D 骨骼、实时物理、服务器下发、社交/通讯录 API |

## 七、当前状态与已知风险

**已验**：`AR Plane` 组件可搭（自动创建 `AR Camera` + `DeviceTracker`）+ 判定式归一化（`vp.y≈0.522`）+ PC 预览完整胜负闭环（hit=100 / fired=294）+ 3D 锚定 Boss 的 Transform 可被脚本驱动（飞行怪实测生效）。

**未验（阻断提审的关键项）**：

| # | 项 | 说明 |
|---|---|---|
| 1 | **真机 SLAM 手感** | "转手机把 Boss 转进准星"依赖真机 SLAM；PC 预览无 SLAM（约 4 s 收敛），**不具手感参考性** |
| 2 | **包体压缩门禁** ★ | 53 帧序列帧真实体积未测，最坏 ≈2.10–3.00 MB → **可能破 2 MB 线** |
| 3 | **端到端音频延迟** | 最坏 ≈98 ms，直接决定打击即时感 |
| 4 | 轨 B 取像运行时行为 | `captureCameraOutput` 仅证明 API 存在；真机帧延迟/挂载未验，**不通过则轨 B 整条砍掉，回落轨 A** |

**已砍项**：吐火球 + 下蹲躲避（实测 APJS 脚本层无任何设备姿态/高度传感器，不可实现）。
