## 关键 API 教训（新）
- **类名是 `APJS.Vector3f`，不是 `APJS.Vector3`**！错写会引发 TS2339/TS2551（引擎报 `Did you mean 'Vector3f'?`）。本地类型声明在 `project/Library/CompiledScripts/Types/APJS.d.ts`，可 grep 查真实签名。
- `Transform` 有 `get/setWorldPosition()` 与 `localPosition` getter/setter 双向可写。
- **`edit_script` 的 `code` 参数必须内联代码字符串**，不支持 `$FILE:` 之类的路径占位符（传了会报 `requires code with 'export class <Name> extends ...'`）。

- `@serializeSceneObjectFlag` 由编辑器在编译时自动注入，**磁盘 `.ts` 里没有是正常的**（勿手动补）。
- `r` 前缀=资源引用 id，`s`=场景对象 guid，`c`=组件；`inspect` 可互查（`inspect r17` → `Boss3D`）。
- 截图口径：`interact_by_dsl`/`capture_preview` 的 screenshot 可能定格在**上次运行的最后一帧**，**不能据此判定"预览在跑"**；要判运行态请看日志时间线。
