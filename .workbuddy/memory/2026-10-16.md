## 补充（09:52）：战弩坐标「锁死」根因 + Boss 开局居中

### 战弩位置为什么运行后被"恢复"（作者提问）
- **根因**：`GameManager.ts` 把战弩基准位**硬编码**了 —— `gunBaseX = 506 / gunBaseY = 1004`，
  而 `updateGunKick()` **每帧**无条件 `gun.setPosition(gunBaseX + recoil*12, gunBaseY + recoil*10)`，
  `resetGame()` 里也是 `setPosition(gunBaseX, gunBaseY)`。
  ⇒ 在编辑器里拖到哪儿都白搭，一跑就被拉回 (506, 1004)。**不是"锁死"，是"每帧覆盖"。**
- **修法**：改成开局从场景读一次。新增 `captureGunHome()`（`gunHomeReady` 一次性保护），
  在 `create()` 里 `this.gun = this.object('古代战弩')` 之后就捕获：
  `gunBaseX = gun.x / gunBaseY = gun.y / gunBaseAngle = gun.angle`（Game2D 的 `.x/.y` 是**左上原点屏幕坐标**，
  内部换算 `x = anchoredPosition.x + scene.width/2`、`y = scene.height/2 - anchoredPosition.y`）。
  之后只在此基准上叠加后坐力偏移 ⇒ 编辑器摆哪儿就是哪儿。
- **实测捕获日志**：`[gun-home] captured x=720 y=916 angle=0`。
  与编辑器实时场景核对：`古代战弩` 的 `anchoredPosition = (360, -275.892)` → 屏幕 (720, 915.9) ✓ **完全吻合**。
- ⚠️ **重要发现**：磁盘 `Assets/main.scene` 里锚点是 `(308.7058, -301.7974)`（→ 屏幕 668.7），
  与编辑器实时值 (360, -275.892) **不一致** ⇒ **作者改过战弩位置但没保存工程**。
  编辑器里调完必须 Ctrl+S 保存，否则重开编辑器会丢。
- 附带发现：x=720 = 屏幕最右边缘（战弩宽 321，右半在屏外）。作者若要贴着右边持弓，这位置合理，待确认。

## 补充（10:05）：像塑「自动保存」机制全摸清 + 外挂守护脚本

### 结论先说
| 路径 | 能力 | 结论 |
|---|---|---|
| MCP 工具 | `save_project`（立刻存一次） | **没有任何 settings/偏好接口** → 无法"通过 MCP 设置自动保存" |
| 编辑器内置 `[Backup] Autosave` | **10 分钟一次**（日志：`next backup in 600 seconds`） | 是**备份副本**，拷到 `Instances/InstanceN/Backup/<时间戳>_x/`，**不写回工程主文件** |
| 外挂守护脚本 | 轮询脏标记 → 有改动就 `save_project` | **能做到 ≈「改完几秒内自动存」** ✅ 已落地 |

→ 所以「拖完不按 Ctrl+S 就丢」是真的：内置 Autosave 救不了主文件。

### 关键通路（跨会话可复用）
- MCP 网关：**`http://127.0.0.1:17320/mcp`**（JSON-RPC over HTTP，`Streamable HTTP`）
  - `GET  /health` → 实例数；`POST /mcp` body `{"jsonrpc":"2.0","id":1,"method":"tools/call","params":{"name":"<tool>","arguments":{...}}}`
  - headers 要 `Accept: application/json, text/event-stream`；**必须绕代理**（`curl --noproxy '*'` / urllib 空 ProxyHandler），否则 127.0.0.1 可能被代理劫持
- 配置自发现：`%LOCALAPPDATA%\DouyinAR\Shared\MCP\Projects\*.json`
  → 里面有 `endpoints.mcp`（网关）、`instanceId`、`toolApproval.autoAllowMcpTools: true`
- `save_project` 实测返回：`{"save_status":"succeeded","save_style":"save","save_duration_orion_part":150,...}`
- **`project_status` 是自动保存的关键**：返回 `is_saved` / `is_changed` / `scene_dirty` / `project_status` / `path`
  → 有它就能做「真·改了就存」，不用傻等固定间隔
- `EditorConfig.json`（同目录 AppLocalStorage 下）只有 UI 布局，**无 autosave 项**
- bundle.jsc 里有 `AutoSaveManager` / `autosave_enable|interval|limit|switch|path` / `BACKUP_INTERVAL` 等符号，
  但 600 秒取不到可配置入口，且它是备份机制 → 不值得逆向改
